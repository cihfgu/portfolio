# Portfolio

Static three-page Arabic RTL portfolio.

## Structure
- index.html
- projects.html
- contact.html
- assets/css/style.css
- assets/js/main.js
- assets/images/*.webp

## Before publishing
1. Replace `your.email@example.com` in `contact.html`.
2. Replace the demo WhatsApp number `966500000000` with the real number (digits only).
3. Replace generic portfolio identity with the preferred display name.
4. Review project descriptions and mark any concept-only work as a training project.
5. Open `index.html` in a browser and test all navigation links and contact links.

The store visuals for the abaya and perfume concepts are illustrative training-project imagery, not screenshots of completed stores.
